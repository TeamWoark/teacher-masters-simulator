# 🎓 المحاكي الذكي للماجستير المهني للمعلمين (إصدار GitHub Pages المتكامل)

منصة محاكاة ذكية للمقابلة الشخصية للمقبلين على **الماجستير المهني للمعلمين**، مصممة على غرار **المحاكي الذكي للرخصة المهنية**، وتضم:
1. **واجهة دخول المتدربين** (اسم مستخدم وكلمة مرور خاصة بكل متدرب).
2. **لوحة تحكم مدير النظام** (إضافة المتدربين **جماعياً من ملف Excel `.xlsx` في كل دفعة جديدة** أو **فردياً**، وتصدير الكشوف والنتائج للإكسل).
3. **نطق عربي استوديوي فصيح ومشكول بالكامل (`MP3` عالي الدقة + محرك تشكيل آلي)** لإنهاء مشكلة النطق الآلي غير الدقيق.
4. **اعتماد الميكروفون فقط بدون كاميرا** مع تحليل تربوي وصوتي وإصدار توصيات فورية لكل سؤال وتقرير ختامي قابل للطباعة.

---

## 🚀 خطوات النشر المباشر على GitHub Pages (خلال ٣ دقائق)

1. أنشئ مستودعاً جديداً (Repository) على حسابك في **GitHub** (مثلاً باسم `teacher-masters-simulator`) واجعله **Public**.
2. ارفع جميع محتويات هذا المجلد مباشرة في جذر المستودع (`index.html`, `.nojekyll`, `audio/`, `css/`, `js/`, `data/`, `vendor/`, `templates/`).
3. من داخل المستودع في GitHub، اذهب إلى:
   **Settings** ⬅️ **Pages** (من القائمة الجانبية) ⬅️ تحت **Build and deployment** اختر:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. خلال دقيقة واحدة سيظهر لك رابط موقعك الرسمي الدائم بصيغة:
   `https://YOUR-USERNAME.github.io/teacher-masters-simulator/`
   *(يعمل الميكروفون والصوت الاستوديوي بكفاءة كاملة لأن GitHub Pages يوفّر بروتوكول `HTTPS` تلقائياً).*

## 📊 إضافة المتدربين (جماعياً من ملف إكسل في كل مرة أو فردياً)

من **لوحة تحكم مدير النظام** ⬅️ تبويب **إدارة المتدربين (إكسل + فردي)**:
1. **إضافة جماعية من Excel:**
   - اضغط **⬇️ تحميل قالب الإكسل الجاهز** (`قالب_إضافة_المتدربين.xlsx`).
   - عبّئ أسماء المتدربين وأسماء المستخدمين وكلمات المرور والدفعة، ثم ارفع الملف في منطقة الإكسل.
   - اختر **إضافة الدفعة الجديدة إلى المتدربين الحاليين** ليتم دمج الدفعة الجديدة دون حذف الدفعات السابقة، أو اختر **استبدال القائمة**.
2. **تمكين المتدربين من الدخول من أجهزتهم وجوالاتهم بعد رفع الإكسل:**
   - اذهب إلى تبويب **☁️ النشر ومزامنة GitHub والإعدادات**:
     - **الخيار الأسرع (بنقرة زر):** أدخل اسم حسابك في GitHub واسم المستودع ورمز الوصول (`Personal Access Token`) مرة واحدة، ثم اضغط **🚀 حفظ ونشر المتدربين مباشرة على GitHub** ليتم تحديث `data/trainees.json` آلياً!
     - **أو الخيار اليدوي بدون أي رموز:** اضغط **💾 تنزيل ملف trainees.json** وارفعه داخل مجلد `data/` في مستودعك على GitHub.
     - **أو المزامنة اللحظية للدرجات والحسابات:** أضف رابط قاعدة بيانات **Firebase Realtime Database** المجانية ليتم حفظ المتدربين ودرجاتهم لحظياً عبر جميع الأجهزة.
